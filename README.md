# MY LITTLE DAYS

## おにぎり弁当版
- 週間の各曜日の達成率は、既存の日別達成率計算を使って水位グラフに表示します。
- その日の達成率が100%になった曜日の具材だけを、1週間かけて弁当箱に追加します。
- 弁当箱と7種類の具材は、元のクレヨン・水彩タッチのおにぎり弁当イラストから切り出した画像素材を使用します。
- 旧クッキングタイム／料理工程用の画像素材は今回の弁当機能では使用しないため、配布ZIPから除外しています。
- 既存のToDo、記録、メモ、データ保存のコードは変更していません。

## 公開
ZIPを展開し、含まれるファイル一式を同じ階層に配置して公開してください。
